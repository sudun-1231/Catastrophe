MDPro3를 종료한 뒤 이전 Catastrophe 팩을 백업하고 `Expansions`에는 최신 팩 하나만 넣어 다시 시작하세요. 공개 MDPro3 미러의 네이티브 코어와 동봉 Lua에서 기존 181개와 신규 34개, 총 215개 시나리오를 검증했습니다. 사용 중인 클라이언트 버전 및 Unity UI에서의 검증은 별도입니다.

현재 카드 21장. 신규 선구자(98013020)와 침공(98013021)은 메인 덱에 추가하세요. 각 카드에 새로 생성한 전용 일러스트를 적용했습니다. 재앙왕·파수꾼·종언룡의 지속 보호는 문서에 맞춰 마법·함정 존을 포함한 필드에서 적용합니다. 기존 샘플 덱은 보존했습니다.

새 팩 재생성: `python3 tools/build_alpha22.py`.

Alpha 0.8~0.21 팩과 문서는 과거 기록으로 보존합니다.
