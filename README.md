# Catastrophe

MDPro3 커스텀 카드군 「카타스트로피」.

현재 테스트 팩: **Alpha 0.25 — 위험 감지 ① 구현·랜서 ② 검증**

- [Alpha 0.25 YPK 다운로드](https://github.com/sudun-1231/Catastrophe/raw/refs/heads/main/Catastrophe_MDPro3_alpha_v25_danger_lancer.ypk)
- [변경 사항·검증 범위](EFFECT_DEBUG_ALPHA25.md)

MDPro3를 종료한 뒤 이전 Catastrophe 팩을 백업하고 `Expansions`에는 최신 팩 하나만 넣어 다시 시작하세요. 공개 MDPro3 미러의 네이티브 코어와 동봉 Lua에서 총 261개 시나리오를 검증했습니다. 사용 중인 클라이언트 버전 및 Unity UI에서의 검증은 별도입니다.

「위험을 감지하는 카타스트로피」 ①을 구현했습니다. 상대가 대상으로 지정한 자신의 다른 필드 카드 1장을 파괴한 뒤 테마 카드를 검색합니다. 공식 무한포영이 용기사를 대상으로 한 체인으로 검증했습니다. 속공 마법이므로 상대 턴에 쓰려면 이전 턴에 세트해 둬야 합니다.

랜서 ②는 양쪽 패·필드 파괴와 턴당 제한을 검증했습니다. 필드는 카드를 골라 파괴하고, 패는 어느 패를 사용할지 고른 뒤 그 패 전체에서 무작위로 1장을 파괴합니다. 발동한 효과 자체를 무효로 하지는 않습니다.

현재 카드 21장. Alpha 0.24의 변경 효과와 기존 능력치·이미지·샘플 덱·파수꾼의 정상 동작을 보존했습니다. 철회된 Alpha 0.23 변경은 포함하지 않습니다.

새 팩 재생성: `python3 tools/build_alpha25.py`.

Alpha 0.8~0.24 팩과 문서는 과거 기록으로 보존합니다(철회된 Alpha 0.23 제외).
