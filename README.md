MDPro3 커스텀 카드군 「카타스트로피」.

현재 테스트 팩: **Alpha 0.21 — 심연룡·재앙왕·파수꾼·종언룡 추가**

- [Alpha 0.21 YPK 다운로드](https://github.com/sudun-1231/Catastrophe/raw/refs/heads/codex/alpha09-fusion-fix/Catastrophe_MDPro3_alpha_v21_new_dragons_links.ypk)
- [변경 사항·검증 범위](EFFECT_DEBUG_ALPHA21.md)

MDPro3를 종료한 뒤 이전 Catastrophe 팩을 백업하고 `Expansions`에는 최신 팩 하나만 넣어 다시 시작하세요. 공개 MDPro3 미러의 네이티브 코어와 동봉 Lua에서 기존 145개와 신규 36개, 총 181개 시나리오를 검증했습니다. 사용 중인 클라이언트 버전 및 Unity UI에서의 검증은 별도입니다.

현재 카드 19장. 신규 카드에는 각각 새로 생성한 전용 일러스트를 적용했습니다. 심연룡(98013016)·재앙왕(98013017)은 메인 덱에, 파수꾼(98013018)·종언룡(98013019)은 엑스트라 덱에 추가하세요. 기존 샘플 덱은 보존했습니다.

새 팩 재생성: `python3 tools/build_alpha21.py`.

Alpha 0.8~0.20 팩과 문서는 과거 기록으로 보존합니다.
