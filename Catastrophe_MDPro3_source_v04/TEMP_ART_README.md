# Alpha 0.4: 임시 일러스트 포함

- 14장에 대해 별도의 임시 일러스트 JPEG를 `pics/`에 추가함.
- 카드 ID: 98013001–98013014. 이미지 파일명은 카드 ID와 동일.
- 모든 CDB/Lua/덱 파일은 Alpha 0.3에서 변경하지 않음.
- 일러스트는 임시 생성 이미지이며 정식 카드 디자인이나 확정 일러스트가 아님.
- 이미지 컷은 한 장의 생성된 콘셉트 시트에서 잘라낸 것으로 작은 디테일과 구도에 한계가 있음.
- Lua 문법 검사 결과는 이전 버전 보고서의 기록이며, MDPro3에서의 실제 실행은 미검증.
- 완전한 효과 구현은 아직 끝나지 않음.
